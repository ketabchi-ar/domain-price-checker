# ⚡ سامانه هوشمند استعلام قیمت و وضعیت دامنه (Domain Hunter)
### Multi-Engine Domain Availability & IranServer TLD Price Checker

یک ابزار کلاینت‌محور (Client-side)، پرسرعت و مدرن برای جستجو و استعلام آنی وضعیت ثبت دامنه‌ها در بیش از **۴۳۹ پسوند مختلف (TLD)** با تعرفه رسمی تومانی **ایران‌سرور (IranServer)**.

---

## 🌟 ویژگی‌های برجسته (Features)

* **استعلام زنده هر نام دامنه یا برند:** کاربر هر کلمه‌ای را وارد کند، سامانه تمام ۴۳۹ پسوند را به صورت موازی چک می‌کند.
* **چندین موتور استعلام موازی بدون محدودیت (Multi-Engine Fallback):**
  1. **Google DNS over HTTPS (DoH):** استعلام سریع رکوردهای NS و SOA.
  2. **Cloudflare DNS over HTTPS:** لایه جایگزین و موازی با تاخیر کم.
  3. **ICANN RDAP Gateway:** پروتکل رسمی بین‌المللی استعلام ریجستری.
  4. پشتیبانی اختصاصی از پسوند ملی `.ir` و ایرنیک.
* **قیمت‌های تومانی دقیق ایران‌سرور:** نمایش قیمت ثبت ۱ ساله و قیمت تمدید سال‌های بعد.
* **فیلترهای هوشمند:**
  * فیلتر دامنه‌های آزاد و قابل ثبت
  * فیلتر پسوندهای محبوب (`.com`, `.ir`, `.net`, `.co`, `.io`, ...)
  * فیلتر اقتصادی (دامنه‌های زیر ۱ میلیون تومان)
* **امکان دانلود گزارش خروجی اکسل (CSV):** با یک کلیک خروجی تمیز با پشتیبانی از زبان فارسی (UTF-8 BOM).
* **لینک مستقیم ثبت در ایران‌سرور:** برای هر دامنه آزاد، دکمه مستقیم سفارش و خرید تعبیه شده است.
* **بدون نیاز به سرور (Serverless):** کاملاً سمت کاربر روی GitHub Pages اجرا می‌شود.
